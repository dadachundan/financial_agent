
# 野村 — 大中华半导体 2026-2030 复兴指南 (Anchor Report, 2026-05-21, 139 页)

> Nomura "Greater China Semi: A guide to Semi renaissance in 2026~30F" Lead analysts: Donnie Teng / Frank Fan (Asia Tech) + Manabu Akizuki (Japan Tech) + Shigeki Okazaki (Japan Chemicals) 全 PDF 为扫描图像，已离线 OCR 至 db；以下页码引用基于报告印刷页码。

## TL;DR (5 要点)

- **核心论断**：AI 算力 + Agentic AI 把半导体技术迭代推到史无前例的速度——单靠先进制程微缩已无法同时满足算力、功耗、散热、带宽与信号速度，**3D 晶体管 + Backside Power Delivery (BPD) + 2.5D/3D 异构封装 + 新材料**取代摩尔定律成为主旋律 (p. 4)。
- **节奏**：关键过渡 **2026 启动**，High-NA EUV 大规模量产要 **2029-30** 才落地，所以==中间 5 年是"材料 + 设备"的爆发窗口期== (p. 4-6)。
- **TSMC 是最大催化剂**：野村估算 TSMC 2027F capex 可达 **~USD 70 bn**（capex intensity ~50%，对应 1.6nm HVM），且 TSMC 同步推动本土供应链——台湾本地零部件采购比 2030F 升至 **~70%** (p. 13-14)。
- **野村给出 8 只 Buy**（详见 §推荐标的）：==新覆盖买入 **AEMC / Kinik / Ingentec**；维持买入 **Besi / Soitec / Dinglong / Anji**；**GlobalWafers (GWC) 从 Neutral 上调至 Buy**，TP 几乎翻倍 (TWD480 → TWD850)== (p. 3, 15-17)。
- **材料重估论**：过去十年半导体材料市值/份额跑输设备和芯片，因 AI 芯片单价与制程复杂度涨幅 > 材料用量。GAA+High-NA+BPD+先进封装+玻璃基板**共同打开材料新增量**，2027F 起进入材料长期重估周期 (p. 18, 20)。

### 第二部分 · 关键技术深入（p. 6-50）

1. **3D 晶体管 + BPD**（p. 6-9）：metal pitch 微缩已逼近极限 (Fig. 5)；Planar → FinFET → GAAFET → CFET 路线下，**ALD/刻蚀/CMP/键合**用量爆发。BPD 工艺把整张电源网络挪到晶圆背面，需要**两片硅晶圆 + 多次键合 + thinning 到 ~1µm** (Fig. 8)——直接利好 Kinik（reclaim wafer + grinding）、Anji/Dinglong（CMP slurry+pad）、GWC（多用硅）。
    
2. **High-NA EUV + 金属氧化物光刻胶 (MOR)**（p. 10-12）：High-NA EUV 数值孔径升至 0.55，PR 厚度从 0.33 NA 时代的 ~25nm 降到 <16nm，**化学放大型 PR 物理失效，必须切到 MOR**（金属氧化物）。MOR 需要**干法沉积 + 干法刻蚀**替代湿法——光刻胶单价翻倍，配套耗材（PR auxiliary）市场扩张。
    
3. **SoIC / 混合键合**（p. 8-9, 40-50）：避免 high-NA EUV "大模"良率难题的另一路径——分切多 die、用 hybrid bonding 重组。AMD EPYC 已经把高性能逻辑拆成 7 个 CCD（14nm 工艺）。Besi 是 hybrid bonding 设备绝对领跑者；TSMC 2026-27 SoIC 产能急速扩张。
    
4. **EUV mask 材料变化**（p. 38-39）：吸收层从 TaBN 转向 Ru / Mo 基低 n 材料；capping layer 也得换。野村注：对掩膜厂增量价值有限——价格主要由 blank defect 决定，不是材料 mix。
    
5. **晶圆键合 NAND（YMTC Xtacking）+ DRAM-on-logic (WoW)**（p. 9）：YMTC 在中端外资品牌商用 WoW 智能手机 / 平板 / 工业 / 汽车应用中已渗透；逻辑+DRAM 用 WoW 键合让 SoC 内存带宽大幅提升，2026-27 主流厂商必标 SoIC + WoW；带动键合、CMP、减薄设备耗材二次爆发。
    
6. **玻璃核心基板 (Glass Core)**（p. 11, 85-88）：相比 ABF 基板，散热更好、翘曲更低、高速信号损耗更小；**Broadcom 是首批量产客户，2027-28 起量**。TGV (Through-Glass Via) 工艺当前单价 USD400-500/unit（小批试产），整片玻璃基板 ASP > USD1,500（vs ABF ~USD200）——要量产必须把 TGV 砍到 ≤USD400。**当前最大瓶颈是 RDL 介电层剥离与分层 (Fig. 146)**——玻璃表面 Si-OH 键合点稀少，ABF 无法机械咬合；CTE 不匹配让铜走线撕脱。野村假设 4Q27F 才会有少量营收贡献给 Ingentec。
    
7. **光通信材料链：InP 与光子 SOI**（p. 11-12, 60-65）：1.6T 光模块 + CPO/NPO 起量，**InP 衬底是供应链最紧的瓶颈**——产线良率 <50% + 中国对铟出口管制 + MOCVD 设备交付 >1 年；2025-27F 持续偏紧，**2028F 开始缓解**（中国厂商扩产 + 国际产能进入）。EML（传统光收发器）和 CW Laser（SiPh-based）是主要需求拉动者；部分需求会被 Ge-on-Si 和 photonic SOI 接走。
    

### 第三部分 · TSMC capex 与本土化（p. 12-14）

- **Capex 趋势 (Fig. 19)**：2024 5nm HVM 期 USD ~38bn → 2027F 1.6nm HVM 期 **USD ~70bn**，capex intensity 逼近 50%。
- **本地化清单 (Fig. 20)**：六大类——设备、零部件、原材料、厂务系统、自动化、消耗品。台湾本地 spare parts 采购比从 2017 的 ~50% 升至 **2030F ~70%**；indirect 原材料 ~70%；overseas subsidiary（亚利桑那 / 日本 / 德国）的本地采购也从 0 拉到 ~60%。
- 直接受益方：**AEMC（PR 辅材本土化）、Ingentec（特气）、Kinik（CMP 耗材）、GWC（硅片）**。

### 第五部分 · 半导体材料市场全景（p. 18-30）

- 2025 全球半导体材料销售 ~**USD 80bn**，IC 制造 / 封装 拆分 ~60% / 40% (Fig. 24-25)。
- 制造材料：硅片占 ~31%、光刻胶 ~13%、光刻胶辅材 ~7%、特气 ~13%、CMP ~7%、靶材 ~3% (Fig. 26)。
- **按地区**：台湾占 30%（全球最大）、中国 20%、韩国 18%、日本 10%、北美 10%、欧洲 8%（Fig. 29-30）。
- 关键供应商 league table (Fig. 35-44)：300mm 硅片 = Shin-Etsu / SUMCO / GlobalWafers / Siltronic / SK Siltron + 国大硅产；EUV blank = Hoya 80% + Shin-Etsu；CMP pad = DuPont / 3M / Fujibo / JSR / 鼎龙 / 其他；CMP slurry = Entegris / Resonac / Versum / Fujimi / 安集 / KC Tech 等；CMP conditioner = Kinik 60-70% + 3M + Saesol + Entegris。

## Highlights — 反共识、易被低估的细节

1. **High-NA EUV 不一定是终局**。野村明确写道：if high-NA EUV proves less cost-effective, the industry pivots to **CFET (Complementary FET) 3D 堆叠晶体管**，这意味着 CMP / 键合 / 减薄设备的天花板可能比当前共识更高 (p. 6, 40-41)。
2. **TGV 工艺成本现状被严重低估**。玻璃基板单 unit USD400-500 的 TGV 成本是当前最大商业化障碍，野村假设要量产必须砍到 ≤USD400——**Ingentec 的玻璃基板营收要到 4Q27F 才有意义** (p. 85)。这与市场对"2026 玻璃基板大年"的预期有明显时间差。
3. **InP 衬底瓶颈不在 epi**。市场常把 InP epi 和 InP substrate 混为一谈，野村拆开：epi 端 IDM（Lumentum/Coherent）紧但 merchant 还闲，substrate 端因 50% 良率 + 铟出口管制 + 长设备交付完全无法解决——**2028F 才有缓解可能** (p. 60-63)。
4. **AMD 已经用 SoIC 路线证明可行**。EPYC CCD 拆分用 14nm 老制程 + 先进封装替代单片大模——是 high-NA EUV 之外的"曲线救国"路线，也是 Besi 受益的根本理由 (p. 8)。
5. **Anji 的两个独立看点经常被合并**：sub-10nm advanced node CMP slurry + 客户 W2W 试产带来的额外 CMP 步骤——后者市场尚未充分计入定价 (p. 130)。
6. **Glass core 不是 ABF 厂商扩产的主战场**。Unimicron 最近 capex 投向 Toray + ASMPT NEXX 主要为了 **Intel EMIB-T**——Broadcom 若想推 glass core 必须自己 co-invest 产能，否则供应链优先级排在 Intel 后面 (p. 85)。
7. **野村对 Besi 的 HB 订单数字明显高于市场**：2026F 70+ 台、2027F 150+ 台，因此 2026 销售低于市场 7%（time-shifted），2027 高 8% (p. 15)。看 Besi 不能只看 next quarter。

## 关键风险（贯穿全报告）

- **AI 资本开支放缓**——所有论点的母级假设。
- **High-NA EUV 推迟**——影响 N1.6 / A10 节点节奏，外溢到 PR 材料生命周期。
- **中国 12 寸硅片产能成熟**——对 GWC / Soitec / SUMCO 直接构成份额冲击。
- **铟出口管制松动 / 中国 InP 衬底产能落地**——光通信链上游可能在 2028 后反转为过剩。
- **TGV 良率与 RDL 剥离问题未解**——玻璃基板时间表整体后移。
- **TSMC 本土化进度低于预期**——直接影响 AEMC / Ingentec / Kinik 的 ASP 与份额。
